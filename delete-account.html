Supprimer mon compte et mes données

Depuis la version 1.8.3, Knight Console permet de supprimer directement et automatiquement un compte connecté et ses données Cloud personnelles.

Suppression automatique dans l'application

  1. Connectez-vous au compte Knight Console à supprimer.
  2. Ouvrez Réglages ou Compte / Cloud.
  3. Choisissez Supprimer mon compte.
  4. Saisissez le mot de passe du compte.
  5. Cochez la confirmation explicite.
  6. Attendez le délai de sécurité de 8 secondes, puis confirmez la suppression définitive.
Attention : l'opération est irréversible une fois terminée.

Données supprimées automatiquement

La procédure vise notamment :

  • le compte Firebase Authentication ;
  • le profil Cloud et l'autorisation Cloud du compte ;
  • les demandes d'accès Cloud associées ;
  • les personnages Cloud appartenant au compte ;
  • les sauvegardes Cloud appartenant à ces personnages ;
  • les liens du compte avec les campagnes.

Un code d'accès Cloud déjà consommé reste invalidé mais son association directe avec le compte supprimé est anonymisée.

Campagnes partagées et données des autres joueurs

Knight Console ne supprime pas automatiquement une campagne partagée lorsqu'un propriétaire supprime son compte. Le compte est détaché et l'identifiant du propriétaire supprimé est retiré de la campagne afin de ne pas effacer les personnages, fiches ou contenus appartenant aux autres joueurs ou MJ.

Données locales

La suppression du compte Cloud n'efface pas automatiquement les données enregistrées localement sur l'appareil. Quand c'est possible, Knight Console conserve également une copie locale du personnage personnel actuellement ouvert afin qu'une suppression de compte ne détruise pas silencieusement la fiche locale.

Si vous ne pouvez plus vous connecter

Si la suppression automatique dans l'application est impossible, vous pouvez demander une suppression manuelle depuis l'adresse e-mail utilisée pour le compte.

Contacter Knight Console

Contact : knightconsole.contact@gmail.com

Données techniques ou partagées pouvant être conservées

Des traces techniques, journaux de sécurité anonymisés ou contenus nécessaires à une campagne partagée peuvent être conservés lorsqu'ils sont nécessaires au fonctionnement, à la sécurité ou à la protection des données des autres utilisateurs. Ils ne doivent pas conserver inutilement le profil ou l'adresse e-mail du compte supprimé.
